# 🛍️ Streetwear E-Commerce Store & Admin Dashboard

مشروع متجر إلكتروني لبيع الملابس (Streetwear) يتيح للمستخدمين تصفح المنتجات، تخصيص الخيارات (المقاس واللون)، وإضافة العناصر إلى سلة المشتريات، مع دعم إتمام الطلبات عبر الموقع أو الواتساب، بالإضافة إلى لوحة تحكم محمية لจัดการ الطلبات.

---

## ✨ الميزات الرئيسية (Features)

- **تصفح المنتجات وسلة المشتريات:** عرض المنتجات وإدارتها ديناميكياً داخل السلة.
- **تخصيص الطلب:** إمكانية اختيار اللون والمقاس والكمية لكل منتج.
- **إتمام الشراء (Checkout):** 
  - نموذج منبثق (Modal) لجمع بيانات العميل (الاسم، رقم الهاتف، ملاحظات الطلب).
  - دعم إرسال الطلبات مباشرة عبر WhatsApp أو حفظها على الموقع.
- **لوحة إدارة الطلبات (Admin Panel):**
  - صفحة مخصصة لطلب العملاء تُعرض بشكل بطاقات منظمة.
  - **حماية بكلمة مرور:** شاشة دخول لحماية بيانات العملاء والمبيعات.
- **الحفظ المحلي (Persistence):** استخدام `localStorage` و `sessionStorage` للحفاظ على بيانات السلة والطلبات.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5:** بناء هيكلية الصفحات والنماذج.
- **CSS3:** تصميم عصري ومتجاوب (Responsive Design) مع Grid & Flexbox.
- **JavaScript (ES6+):** 
  - إدارة حالة السلة والطلبات (DOM Manipulation).
  - حماية شاشة الإدارة وإدارة الجلسات (`sessionStorage`).
  - التخزين المحلي للبيانات (`localStorage`).
